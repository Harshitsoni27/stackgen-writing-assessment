# Task 3

## Improved Meta-data

```  
XML

description: Explain how to set up and monitor StackSync AI Connector in StackBuilder. 

title: StackSync AI Connector   
read_time: ‘4 min read’  
clusters:   
	- stackbuilder  
customFields:   
ai_index: true   
audience:   
- developer  
- DevOps   
product_version: '1.0'   
```

## Metadata Field Definitions

**ai\_index**: When this field is set to be “true”, it will tell StackGen to index the particular document and make it researchable in their AI-powered tools such as “Sara”, the StackGen AI guide, or the DevOps Copilot “Aiden”.

**clusters**: This field specifies which product areas, or guide sections this documentation belongs to (eg, stackbuilder-guide, stackgen, or cli). It is categorial tag that helps organize and categorize the documents.

**read\_time**: This field estimates how long it takes to read the documentation, displayed to users at the top of each documentation page. This help users to decide if they have a bandwidth to read through the document or bookmarked it for future reference.
